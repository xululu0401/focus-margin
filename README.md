# 景深对账台 dof-ledger

> 「我想让这一段都拍清楚」——对焦该放哪、光圈最小开多大，算清再拍。

「景深对账台」是一个纯本地单页应用：填**画幅、焦距、光圈、对焦距离**，它算出**实际的清晰范围**（近点到远点）、超焦距、前后景深、无限远背景弥散圆、**衍射转折光圈**与**等效口径**；再给出**目标区间的闭式反推**——要让「从这里到那里」整段清晰，对焦要放在哪、光圈最小开多大，并回代验算。零依赖、零网络请求，`index.html` 单文件可直接双击打开。

## 是什么

- **输入**：弥散圆口径（对角线 ÷1500 / ÷1730 / ÷1000 / 像素级 / 自定义）、波长 λ、对照画幅、目标近点与远点（可勾「远点取无限远」）、反推用焦距；以及 1–8 个方案（各自选画幅，填焦距 / 光圈 / 对焦距离）。
- **每个方案输出**：超焦距 `H`、近点 `Dn`、远点 `Df`、前景深、后景深、总景深、前后比、无限远背景弥散圆（mm 与占画幅高 %）、该画幅的衍射转折光圈 `N_d` 与是否已越过、**目标区间覆盖判定**与两端缺口、等效焦距与等效光圈。
- **全局输出**：反推对焦距离 `s*` 与最小光圈 `N*`（含回代残差）、「对焦在区间中点」这个常见做法的实际后果对照、同一区间换焦距所需光圈的对照表、对焦位置口径对照（H / H÷2 / H÷3）、敏感性（焦距 ±20%、光圈 ±1 档、对焦距离 ±20%、换画幅，逐行完整重算）、13 项结构自检。
- **可导出**：CSV / Markdown / 1080×1350 结果卡 PNG / JSON 备份，另有本机保存与刷新恢复、备份导入。
- **可操作**：反推结果、超焦距对焦、H÷3 对焦、等效画幅换算都能一键作用回输入并立刻重算。

## 关键公式（页面与测试都按这一套）

```
D    = √(W² + H²)                     画幅对角线
c    = D ÷ divisor                    弥散圆（显示约定，不是物理常数）
H    = f²/(N·c) + f                   超焦距
Dn   = s(H − f)/(H + s − 2f)          近点
Df   = s(H − f)/(H − s)               远点（s ≥ H 时为 ∞）
b    = f²/(N(s − f))                  无限远背景的弥散圆直径
dA   = 2.44·λ·N                       艾里斑第一暗环直径
N_d  = c/(2.44·λ)                     衍射转折光圈
k    = 43.2666153 ÷ D                 等效系数（参照全画幅）
```

反推（闭式解）：

```
远点有限： s* = 2·Dn*·Df* ÷ (Dn* + Df*)      ← 调和平均，与 c、N、f 都无关
           N* = (Df* − Dn*)·s*·f² ÷ (2·c·(s* − f)·Dn*·Df*)
远点 = ∞： s* = 2·Dn*
           N* = f² ÷ (c·(2·Dn* − f))
```

两条可被测试守住的恒等式：

- 对焦在 `H` 上时，**近点恰好是 `H/2`、远点是 `∞`**（与 `f`、`N`、`c` 都无关）。
- 对焦在 `H/3` 上时，**前 : 后 = `H : (2H − 3f)`**，前段占总景深 `H/(3(H−f))`——所以经典的「前 1/3 后 2/3」只是 `f → 0` 的极限。

## 怎么用

1. 用浏览器打开 `index.html`（无需服务器，双击即可）。
2. 在左侧填口径与**目标区间**（你想让哪一段清晰），再按需要增删方案。
3. 看「反推」卡：对焦放哪、光圈最小开多大；点方案表里任意一行看该方案详解与建议按钮。
4. 需要存档时导出 CSV / Markdown / 结果卡 PNG / JSON 备份。

构建：`node build.cjs`（把 `core.js`、`ui.js` 内联进 `template.html` 生成 `index.html`）。
测试：`node --test tests/core.test.cjs`。

### AppCore API（挂载于 `window.AppCore`，全部为纯函数）

| 方法 | 说明 |
| --- | --- |
| `optics(f, N, sMm, c, lambdaMm)` | 单个方案的光学量（H / Dn / Df / 前后景深 / 背景弥散圆 / 艾里斑 / N_d），单位 mm |
| `coverage(dn, df, nearMm, farMm, farInf)` | 目标区间覆盖判定与两端缺口 |
| `solveTarget(cfg, f)` | 闭式反推 s* 与 N*，含回代残差与「中点点焦」对照 |
| `solveTable(cfg)` | 同一目标区间下 16/24/35/50/85/135 mm 各需多大光圈 |
| `laws(cfg)` | 两条恒等式的实测值与理论值、对焦位置口径对照表 |
| `normalize(raw)` | 规范化 + 校验 → `{ok, cfg, errors, warnings}`，不抛异常 |
| `analyze(raw)` | 主入口：`{ok, cfg, rows, laws, reverse, sensitivity, insights, checks}` |
| `verify(res)` | 13 项结构自检 |
| `sensitivity(cfg, idx)` | 逐行完整重算的敏感性 |
| `fmtDist / fmtMm / fmtPct` | 距离 / 长度 / 百分比格式化 |
| `defaultsClone()` | 默认虚构样例的深拷贝 |

## 这份账不算什么

只做**几何光学**：不建模镜头像差、场曲、真实分辨率（MTF）、呼吸效应、浮动对焦、机身防抖与快门运动模糊——「清晰」的另一半不在本页。薄透镜理想化，距离都是相对镜头的物距；光瞳放大率按 1（近摄时结论偏差可能变大）。弥散圆是显示约定，换口径会改变结论。不处理移轴、焦点合成、滤镜与 T 值差异。**不联网、不测量任何真实镜头、不做器材评价或购买建议。** 默认样例与 6 个内置场景**都是虚构示例**，不是任何真实器材的实测数据。
